# 升本流 · 英语专站

河南专升本公共英语（2027-03-20）刷题站。打开 `index.html` 即可用，无需安装。

线上：https://wcqdw.github.io/shengben-english/

## 里面有什么

- **考点词 120 条**：A 句型触发 30 / B 词性组 30 / C 动词搭配 30 / D 定位词 30。每条只写「考法 + 答案形态」，不堆中文释义。
- **改错 30 题**：挂十类考点标签（主谓一致 / 时态语态 / 非谓语 / 词性误用 / 介词搭配 / 冠词代词 / 比较级最高级 / 连词从句 / 单复数 / 固定搭配），每题带解析。
- **回炉机制**：答对升级并顺延，间隔 1/2/3/5/8/14/30 天；答错归零，次日回炉。
- **今日三件**：10 词 + 10 改错 + 回炉，按日期与到期错题自动算出，不需要自己排计划。
- **整卷计时**：120 分钟，到点锁卷，不许再答。

## 数据说明

进度只存在浏览器本地（`localStorage` 键 `sf_en_v1`），不上传、不跨设备。换设备前在「我的 → 导出备份」拿 JSON，到新设备「导入备份」。

## 文件

- `index.html` — 页面外壳与样式
- `data.js` — 题库（考点词、十类、改错题、考试日期）
- `app.js` — 回炉、判分、视图、计时逻辑

改题库只动 `data.js`；改交互只动 `app.js`。本地那份单文件版《升本流·英语专站.html》仍可离线直开。
